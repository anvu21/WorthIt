# Worth It Food Map — Project Brief for Claude Code

## What we're building

A map of every restaurant featured on BuzzFeed's *Worth It*, with a personal "been there" checklist and filters (price tier, country, city, season, visited, closed, chain). Data comes from a hand-maintained Excel workbook (`Data/Worth It Places Visited.xlsx`). The site is public; anyone can use it, and each visitor's checklist lives in their own browser.

**Guiding constraint: cost ≈ $0.** No database, no API, no Lambdas. The site is a static React build plus one JSON data file, served from the existing oil project's CloudFront distribution under `/worthit/`.

## Architecture

```
Data/Worth It Places Visited.xlsx
        │  python -m worthit_import            (runs on your PC)
        │    - parse Map sheet (restaurants) + Main sheet (items)
        │    - clean: =HYPERLINK(), "CLOSED " prefix, multi-line cells, price labels
        │    - assign stable IDs (carried over from the previous JSON)
        │    - geocode only uncached addresses (Nominatim, 1 req/s)
        │    - print diff vs previous JSON, write on confirm
        ▼
frontend/public/data/restaurants.json   +  importer/geocode_cache.json   (both committed)
        │  git push → GitHub Actions deploy.yml
        ▼
S3: worthitfood-prod-site-<acct>/worthit/**  ◄── oil CloudFront behavior "/worthit*"
                                                  (CloudFront Function rewrites /worthit → /worthit/index.html)
Browser: map + filters + checklist  ── visits in localStorage["worthit.visits.v1"]
```

### Why things are where they are

- **Own bucket, shared distribution.** Oil's deploy does `aws s3 sync --delete` on its bucket, which would wipe anything else there. A separate bucket isolates the two deploys; adding a second origin + one cache behavior to oil's distribution costs nothing.
- **The `/worthit*` routing lives in oil's Terraform** (`oil/oil_price_project/terraform/modules/frontend`), because a CloudFront distribution can only be managed by one state. It is gated on the `worthit_bucket_regional_domain` variable — empty string = no WorthItFood origin.
- **Apply order:** WorthItFood `infra.yml` first (creates bucket + policy allowing oil's distribution), then set `TF_WORTHIT_BUCKET_DOMAIN` in the oil repo and re-run oil's `deploy-infra.yml`.
- **No client-side routes.** Oil's distribution maps every 403/404 to oil's `/index.html`; WorthItFood keeps state in the URL hash (`#p=<id>`) so nothing depends on path routing.
- **Nominatim, not Mapbox.** Mapbox's free geocoding forbids storing results; we store coordinates. Nominatim data is ODbL (attribution shown in the map). Respect its policy: ≤1 req/s, identifying User-Agent, results cached forever in `geocode_cache.json`.

## Data model (`restaurants.json`)

```json
{
  "schema": 1,
  "generated_at": "2026-10-30T12:00:00Z",
  "restaurants": [{
    "id": "k3f9qa",                 // 6-char, stable forever once assigned
    "name": "Sushi Stop",
    "closed": false, "chain": true,
    "address": "2218 Sawtelle Blvd, Los Angeles, CA 90064",
    "city": "Los Angeles", "country": "USA",
    "lat": 34.0376, "lng": -118.4405,
    "website": "https://sushistop.com/",
    "tiers": ["$"],                  // union of appearance tiers: $, $$, $$$, side, special
    "appearances": [{ "title": "$3 Sushi Vs. $250 Sushi", "season": "1", "episode": 1,
                      "tier": "$", "video": "http://www.youtube.com/watch?v=...", "published": "2016-09-18" }],
    "items": [{ "name": "Bluefin Nigiri", "cost": 4.0, "voters": ["Steven"] }],
    "notes": null
  }]
}
```

### Spreadsheet rules the importer enforces

- `Map` sheet = one row per restaurant (authoritative list). `Main` sheet = one row per item, joined to Map by normalized name (+ address when names collide, e.g. two Pasta Sisters).
- Columns are found **by header name**, not position. Optional `Lat` / `Lng` columns on `Map` override geocoding.
- Names: strip `=HYPERLINK(url, "Name")`, leading `CLOSED` → `closed: true`.
- Multi-episode cells are newline-separated; `-` lines are separators and dropped.
- Price Point: `$ / $$ / $$$` kept; `Side Trip` → `side`; `One Stop`, `Holiday Special` → `special`; `n/a`/blank → null.
- U+FFFD (`�`) characters are lossy in the source file: fixed heuristically in titles (`" � "` → `" – "`, `"�s"` → `"’s"`) and reported as warnings everywhere else.

### Stable IDs (critical — visitors' checklists reference them)

`id` = base36 of sha1(normalized name | normalized address)[:6] on first sight. On every later import, a row reuses the previous JSON's ID when: (1) same name+address, else (2) the only unmatched old entry at the same address (rename), else (3) the only unmatched old entry with the same name (moved). Never change this logic without a migration plan.

## Visitor state (`localStorage`)

- Key `worthit.visits.v1` → `{ "v": 1, "visits": { "<id>": { "date": "YYYY-MM-DD", "note": "" } }, "lastBackup": "<iso>" }`
- Export = download that JSON. Import = file or sync code; **merge by default** (keep earliest date), replace optional.
- Sync code = `WI1.` + `.`-joined `<id><date-as-base36-days-since-2016>` tokens — short enough to text yourself.
- Safari evicts script storage after 7 days without a visit (unless installed to Home Screen) → show a backup nudge when ≥ 5 visits and no export in 14 days.

## CI/CD

| Workflow | Trigger | Does |
|---|---|---|
| `ci.yml` | PRs + pushes | pytest importer; `python -m worthit_import --check` (JSON is in sync with the xlsx, no network); `npm run build` |
| `deploy.yml` | push to `main` touching `frontend/**`, `Data/**`, `importer/**` | build → `s3 sync dist/ s3://$BUCKET/worthit/ --delete` (hashed assets immutable, `index.html` + `data/*.json` no-cache) → CloudFront invalidation `/worthit/*` |
| `infra.yml` | changes under `terraform/**` | plan on PR, apply on `main` |

GitHub repo **variables**: `SITE_BUCKET`, `CLOUDFRONT_DISTRIBUTION_ID` (oil's). **Secrets**: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` (same IAM user as oil).

## Key constraints

- Never hand-edit `restaurants.json`; edit the xlsx and re-run the importer.
- The importer must be deterministic and idempotent: same xlsx + same cache ⇒ byte-identical JSON (sorted keys, sorted restaurants by id).
- `--check` mode must not touch the network; CI fails if an address is missing from `geocode_cache.json`.
- Frontend must work with zero backend: everything is filtered client-side (~250 rows).
- Vite `base: '/worthit/'`. Never use path routes.
- Map tiles: OpenStreetMap standard tiles (free, keyless; CARTO now requires an API key). Attribution must credit OpenStreetMap. If traffic ever grows, move to a keyed provider.
